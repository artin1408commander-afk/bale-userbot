# Bale Userbot (شخصی)

یوزربات ساده برای **اکانت شخصی** پیام‌رسان بله.  
فقط برای شماره `+989039865450` طراحی شده و روی **Termux** اجرا می‌شود.

## چیکار می‌کنه؟

1. موقع استارت چک می‌کنه سشن قبلی (`session.bale`) معتبر هست یا نه.
2. اگر معتبر بود → مستقیم لاگین می‌کنه (بدون OTP).
3. اگر سشن نبود یا منقضی شده بود → کد OTP می‌فرسته، شما کد رو می‌دید، لاگین می‌شه و سشن رو ذخیره می‌کنه.
4. بعد از لاگین موفق، اطلاعات اکانت رو نشون می‌ده.

فعلاً فقط بخش لاگین و ذخیره سشن پیاده شده. بقیه قابلیت‌ها بعداً اضافه می‌شن.

## پیش‌نیازها (Termux)

```bash
pkg update -y
pkg install python git -y
pip install --upgrade pip
```

## نصب و اجرا

```bash
# کلون کردن پروژه
git clone https://github.com/artin1408commander-afk/bale-userbot.git
cd bale-userbot

# نصب کتابخانه
pip install -r requirements.txt

# اجرا
python main.py
```

### اولین اجرا
- از شما کد OTP می‌پرسه (که به گوشی‌تون پیامک یا داخل بله می‌آد).
- بعد از وارد کردن کد، فایل `session.bale` ساخته می‌شه.

### اجراهای بعدی
- اگر `session.bale` معتبر باشه، بدون OTP لاگین می‌شه.

## نکات مهم

- فایل `session.bale` = کلید ورود به اکانت شماست. **هیچ‌وقت** به کسی ندید و داخل گیت کامیت نکنید.
- شماره داخل کد ثابت است (`989039865450`). اگر خواستید عوض کنید، در `main.py` تغییر بدید.
- برای توقف: `Ctrl + C`
